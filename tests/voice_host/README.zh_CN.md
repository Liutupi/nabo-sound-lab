# 复读变声音质测试

在仓库根目录运行，需要 Python、NumPy、Node.js 和 C 编译器：

```sh
NV_UBSAN=1 python3 tests/voice_host/test_quality.py
```

测试生成12种确定性输入：空录音、小声/正常/大声合成音节、碰麦脉冲、直流偏置、
静音、微弱噪声、短录音、奇数长度录音、满幅输入和超过3秒上限的输入。
每种输入均覆盖12种生产变声及实际原型参考实现，无需私人语音、下载样本或历史金样目录。

检查 ADPCM/增益逐样一致、播放时长和波形一致性、任意录放分块边界、变声音高与机器人边带、首尾包络、
限幅余量。独立质量指标要求小声音节达到可用数字电平，输入音量变化后输出差异受控，
单次碰麦不压低整句，直流被去除，6kHz混叠受抑制，3kHz语音频段得以保留，
对讲机尾噪不盖过人声；同时约束录音/播放器结构大小。生成样本和报告仅留在忽略的
`out/voice-quality/` 下。

录音仍保留3秒8kHz IMA ADPCM。降采样前加入去直流和15抽头滤波，播放从线性改为
三次插值。增益取超过微弱噪声底限的20ms解码RMS窗口的80分位，最多32倍，
不再受整段最大峰值支配；没有此类窗口时保持1倍。各效果分别补偿响度，并在满幅的
0.75以上软限幅，保留峰值余量。机器人混入清晰人声，去掉粗糙降位；对讲机滤波状态
保留小数精度，尾噪降低并跟随录音电平，完全静音不会产生尾噪。
录音写入及停止/播放交接共用音频互斥锁。主音量、NVS格式、素材和分区不变，
麦克风硬件增益不变。

这些测试验证数字处理行为，不能证明工牌的可懂度或主观听感。8kHz录音带宽与小喇叭
仍有限制。实机应保持相同主音量，用普通说话对比小声音节、停顿、大声词、换声音和
OK停止，检查底噪、辅音、变声区分度、破音、音频任务耗时及舒适度。
增益上限和合成信号测量不能当作实际声学增益保证。
