# 按键、复读与音量交互测试

本次源码更新保留现有音乐人造型、配色、素材分区、音色算法和 NVS 格式，不替换
任何冻结发布镜像或原有实机验收记录。

## 操作

- 共用底栏按键提示在按下时立即高亮，至少显示 160 ms。▲ 在原有 300 ms 双击
  判断窗口内保持高亮；实际动作仍等待该窗口，避免双击返回时先修改设置或播放
  声音。反馈不新增提示音、输入延迟或阻塞工作。自定义底栏页面保留既有反馈。
- 在音量行按 OK 进入调整，▲ 每次减 10%，▼ 每次加 10%；0% 和 100% 到边即停，
  不循环跳转。OK 完成；双击 ▲ 返回设置列表，再双击返回菜单。实际数值变化沿用
  异步音量应用和延迟 NVS 保存；返回时保留选定值。
- 复读仅在空闲时提示录音，手动录音时提示松开 OK，手动和自动播放中均提示
  OK 停止。播放中按 OK 使用原有淡出停止；松开这次按键不会误开或结束新录音，
  手动模式再次按住才开始录音。
- 录音和播放中均可选择音色；播放中换声音，会用新声音重播保留的录音，让名称、
  动画与声音保持一致。随时可切换手动/自动模式，切换前先取消当前录放，避免自动
  模式连续工作时锁住选择。自动模式保留冷却时间，离开页面停止录放。音色切换直接
  更新卡片，不再用弹出提示遮挡操作。
- 浏览器原型同步演示这些操作，并在本机保存音量。其旧占位造型仍属原型限制，
  不作为当前固件美术或真实音频验收依据。

## 运行

需要 Python 3.10+、NumPy、Pillow 和原生 GCC/Clang C 编译器；`CC` 可指定编译器，
默认 `cc`。

```sh
python -m pip install numpy Pillow
python tests/interaction_host/run_tests.py
NABO_UBSAN=1 python tests/interaction_host/run_tests.py
node tests/interaction_host/test_prototype.js
```

最后一条命令另需 Node.js。测试运行真实 C 操作处理、音频/变声、渲染器和冻结素材包。
仅在宿主侧观察文本、字形覆盖、实际文字边界、设置保存请求及音量交接。共享库和
改名的渲染观察入口位于临时目录；截图写入忽略的 `out/interaction-host/`。

覆盖按键即时反馈及消退、重复按下抑制、uint32 时钟回绕、单/双击 ▲ 分离、音量
上下界、保存/应用钩子、手动与自动录放、停止不误录、自然结束、播放中换声、自动录放中退出模式及
返回清理。每张截图均检查缺字、文字实际边界、显示列表容量和增量/整屏像素一致性。
测试不打开串口或刷机。实体按键、实际音量、中文面板显示及听感仍需上板验收。
