# NABO 声音实验室 · 开口就有戏

把工牌，玩成你的随身乐队。

不用先学会一门乐器，先说一句、哼一声、拍一下。戴上耳机的 NABO 音乐人，会把你的声音变成有反应、有表情的小现场。开机那句熟悉的“那波，陪你玩音乐！”，就是这间口袋声音实验室的开场白。

【玩声音：8种互动，开口就有戏】
• 复读 NABO：按住 OK 说一句，NABO 换个声音学回来。花栗鼠、大叔、机器人、倒放、山谷回声、没电了、颤音、外星人、对讲机、合唱团、卡带结巴和原声，12种声音轮流玩，还能切换自动复读。
• 喊叫 NABO：小声走、大声跳。试着用声音越过障碍，看看能跑多远。
• 吹蜡烛：对着工牌吹一口气，把屏幕里的蜡烛吹灭；生日模式和计时挑战，让一个小动作也有仪式感。
• 走钢丝：把一个长音唱稳，让 NABO 慢慢走过钢丝，看看自己的声音能保持多久。
• 声部卡：探索低音与高音，看看自己的音域、跨度和声音小卡片。
• 哼歌飞行：先哼一个舒服的音定下基准，再哼高向上、哼低向下。12道门、三次机会、三档难度，试试用声音“开飞机”。
• 拍手节奏：先听4拍预备，再跟着光圈拍16拍。精准、命中、连击都会反馈，和自己的上一局比一比。
• 采样琴：录下最多半秒声音，用三个按键弹出三个音高。一声短哼、一个短音，都可以成为你的小旋律。

【看声音：5种可视化，给歌声换个样子】
频谱仪让声音跳成霓虹柱；声纹瀑布把说话和歌声留下轨迹；示波器展现波形；和弦环观察音级分布；分贝计让声音大小有迹可循。说话、哼唱、弹琴，都会遇见不同的画面。

【练音乐：4组工具，随手练一会儿】
调音器提供半音、吉他和尤克里里模式；吉他工具箱里有和弦谱、听和弦、扫弦节奏、变调夹、指板音阶与练耳挑战；还可以用节拍检测和音准曲线观察节奏、跟着旋律练习。工具供入门与趣味参考，精度边界见下方使用说明。

【属于 NABO 的小舞台】
白帽、圆框眼镜、品红耳机和黑色夹克，沿用“NABO 音乐人”定稿造型。变声、打鼓、弹琴、飞行都有相应演出。全程离线，不用配网；音量0–100%可调，0%静音，自动记住你的选择。

想轻松玩两分钟，或在练琴间隙换换脑子，就把声音交给 NABO。你负责发声，NABO 负责陪你玩。

本页五张图片采用定稿角色、道具与固件界面排版合成，非设备实拍。当前为首个公开版 v0.1.2，版本边界和反馈说明见“使用方法”及 GitHub 验证记录。

## 使用方法

1. 准备与安装
适用于 FoloToy AI Passport（ESP32-C3 / 8MB Flash / 240×320）。这是独立离线固件，不需要 Wi-Fi，不包含小智联网对话。先备份自己的原固件和设置，再使用本页安装入口或官方网页刷机工具安装完整 .bin。命令行首次安装地址为0x0；不要把分立app当完整固件刷入。

完整固件、校验和、升级说明：
https://github.com/Liutupi/nabo-sound-lab/releases/tag/v0.1.2

2. 第一次开机
开机会播放“那波，陪你玩音乐！”。按 OK 进入菜单；菜单中用 ▲▼ 选择、OK 进入。双击 ▲ 返回上一级，各玩法的具体操作以屏幕底栏为准。约五分钟无操作后会休眠，按实体 OK 唤醒。

3. 先试三个一分钟玩法
• 复读 NABO：▲换声音，▼切换手动/自动。手动时按住 OK 说一句，松开后听 NABO 学回来。
• 哼歌飞行：先稳定哼一个舒服的音，再按 OK 将它设为基准；随后哼高向上、哼低向下。OK暂停/继续，▼重来；开始前可用▲切换难度。
• 拍手节奏：按 OK 开始，听完4拍预备，再跟着光圈拍16拍；准备页用▲切换速度。找相对安静的位置，避免旁边的音乐或说话声触发。

4. 把声音弹出来
进入采样琴后，按住 OK 录下最多半秒声音。采样完成后，轻按 ▲、▼、OK 分别弹原音、升4半音和升7半音；需要新素材时再次按住 OK。双击▲返回。录音只在当前玩法的内存中使用，离开时释放，不写入Flash。

5. 看声音、练音乐
在“看”分组打开频谱、瀑布、波形、和弦环或分贝计；在“练”分组打开调音器、吉他工具箱、节拍检测和音准曲线。跟随每页底栏切换模式，调音参考的A4基准可在设置中调整。

6. 音量与日常使用
设置第一行是音量。▲▼选择项目，OK每次增加10%，100%后回到0%；0%真正静音。停留约1秒后自动保存，重启记忆，默认80%。还可调整A4、减弱闪烁、安静阈值、dB校准及频谱灵敏度。

7. 首版体验说明
• 含噪440Hz输入曾被识别为约147Hz，调音/音高功能供趣味与入门参考，不能当作专业测量结果；拍手和吹气也会受环境影响。
• 部分变声演出UI有慢帧；新版是否仍有主观爆破音，尚待更多实物听感反馈。
• 早期r1修订曾在无人操作时返回菜单/重启，后续观察未复现，但原因仍未定位。
• 当前实物验证覆盖同分区app与素材升级及完整回读；完整包包含匹配构建输出的新boot，尚未另做首次整包安装的端到端实测。
