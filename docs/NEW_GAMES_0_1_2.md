# 0.1.2 新增三个声音玩法

2026-10-23。根据用户要求完成原菜单三个占位项目，复用已批准 NABO 音乐人素材，无新美术。新增规则标准和可玩原型为 `prototype/new-games.html`，纯规则对应 `prototype/new-games-model.js` 与 `firmware/main/ui/newgames_model.c`。`DESIGN.md` 和主原型菜单已同步加入三个实际玩法，本文是本轮明确的规则补充。

## 哼歌飞行（flight）

- 开始前哼一个舒适、稳定的音，OK 将当前音高校准为中线；未检测到可靠音高时不开始。之后唱高向上、唱低向下，每半音约 6 像素，位置限制在场内。300ms 短暂断音保持，之后缓慢下沉。
- ▲在准备/结束时选择轻松、标准、挑战；门洞分别88/74/62像素，速度60/72/84像素每秒。▼重来，运行中OK暂停/继续；双击▲始终返回。
- 固定角色横坐标54，依次通过12道门。每道门只判断一次，角色中心需落在洞内并留12像素半径。成功得10分，连击额外加2/4/6/8/10分；失败扣1生命，3生命用尽结束。完成12道门且仍有生命即过关，OK可重新校准再来。
- 使用 S-FLOAT，不修改画中的头左脚右姿态；移动由引擎承担。障碍使用同一 mulberry32 种子，C与JS完全相同。

## 拍手节奏（clap）

- ▲在准备/结果时切96/120/144BPM。OK开始或重开，▼回准备，双击▲返回。
- 先外放4声预备拍，然后跟光圈拍16次；正式16拍不继续外放节拍，避免自家扬声器的静音保护窗口吞掉拍手。没有持续音轨占用麦克风。
- 使用真实 `g_onset_hook` 起音采样时刻与 `sl_audio_time()` 的同源时钟；与现有原型约定一致补偿45ms，采用按起音时间判定，不能用UI渲染时刻代替。小于-50dBFS的候选忽略；160ms防连击抖动，每拍仅可命中一次。
- ±45ms得100分，±120ms得60分，窗口外多拍扣10分（不低于0）；漏拍不加分并中断连击。16拍结束显示得分、命中、精准、最大连击、漏拍和多拍。NABO每次有效命中触发一次 S-DRUM。
- 浏览器另有C键/“拍一下”测试按钮，只用于独立检查规则，不会被说成真实麦克风验收。

## 采样琴（sampler）

- 按住OK超过350ms开始录音，松开结束，最多0.5s自动结束。短于40ms或峰值低于64/32768判为无效，给出重录提示。没有表、数字或联网音频上传。
- 轻按▲/▼/OK分别演奏原音、+4、+7半音；单声部，下一键切换当前音。短按OK在松开时触发，避免与按住采样混淆。▲单击立即弹奏，300ms内再按▲执行返回（首个音允许响一下）。
- 真实输入经 `sl_mic_samples()` 计数、`sl_mic_last()` 快照取得，计数前后核对，避免复制过程中音频写指针改变。最长一次补读2048个16k输入；超过该缺口明确提示“采样中断，请重录”，不把断裂的声音当成功采样。
- 两个16k输入平均下采样为8k/16bit，4000样本正好8000字节；进入玩法按需分配，离开先停止录放再释放。临时补读最多4KB在UI栈，不是第二份常驻PCM。新静态规则状态约88字节，采样状态少于百字节。
- Q16线性插值变调，4ms淡入淡出，峰值归一目标约12000、最多4倍增益，单声部输出保留18000峰值上限；全局混音器仍作最终饱和。重采样会连同时长改变，符合玩具式变调，不宣称音色保持的专业音高算法。
- 采样只在内存，不存Flash/NVS，也不跨离开玩法保留。复用 S-GUITAR-IDLE / S-GUITAR-STRUM 表演。

## 固件集成合同（由主代理完成）

新增编译文件：`firmware/main/ui/{newgames_model.c,sl_sampler.c,sc_newgames.c}`。

- `sc_newgames.h` 提供 `SC_FLIGHT`、`SC_CLAP`、`SC_SAMPLER`；将三个场景加入 scenes 表，将菜单原“设计中”行改为对应 scene。ID 为 `flight`、`clap`、`sampler`。
- 平台增加 `uint32_t sl_mic_samples(void)`，返回真实输入环的原子写计数 `atomic_load(&s_wp)`；在 `sl_ui.h` 声明。宿主也要提供输入环写计数。不得拿分析 hop 计数替代，因为喇叭busy时会跳过分析。
- 在 `sl_audio_fill()` 已持有 `sl_audio_lock` 的混音段调用 `sl_sampler_mix(acc,n)`，在输出限幅、any及电平统计之前。mix自身不加锁，避免递归死锁；采样器其余公开状态修改/查询均持同一音频锁。该接口不会自己新建音频任务或占用设备。
- `sl_newgames_status(char *out,size_t n)` 追加当前玩法状态/分数/命中/采样长度/录放信息，便于后续真机复核。
- 新玩法画面关键指令和返回提示使用sans16，底部始终留可见 `▲▲ 返回`；数字不依赖mono14小字。请重新生成包含新C字符串的字体子集后打0.1.2资源，不能沿用缺这些新字的0.1.1字体。
- 原型可从 `new-games.html?game=flight|clap|sampler` 进入；默认页是3玩法选择。`prototype/index.html` 的三个菜单入口和右侧快捷链接已接入，菜单为6行/24px行高/16px主中文；新页顶部可直接返回 `index.html?screen=menu`。
