## 已知问题

1. 含噪440Hz实际输入主峰约440Hz时，当前DSP曾报约147Hz子谐波；未修改算法，也未宣称全频/含噪±5cents精度通过。
2. r1修订在用户明确未操作时曾返回菜单/重启，原因未定位；r2/r3后续三段各约123秒及r4观察未复现，不能据此称已修复。
3. 部分变声演出UI有慢帧。新版边界淡入/淡出与首次录音预初始化已采用，但实体是否仍有“啪/爆破”声，尚待用户听感确认。
4. 当前实物保留旧boot（SHA82bdd748…becf1），生成merged采用构建boot（SHA9255b6d5…541c）；本次没有用完整包重做首次安装的端到端测试。
