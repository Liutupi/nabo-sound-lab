# NABO 声音实验室 v0.2.0-preview.2

2026-10-24发布，适用于 FoloToy AI Passport，ESP32-C3 / 8MB Flash。
本预览版使用用户工牌上已验收的同一份无线应用。内部版本保留 **0.2.0-dev**，
直接打包冻结二进制，没有为修改版本号重新编译。稳定版v0.1.2仍可下载。

## 相比preview.1的变化

- 底部按键提示即时高亮。复读按录音/播放状态显示操作，OK停止播放，松开不误录。
- 设置里选中音量后按OK进入调整，▲减、▼加，0–100%到边即停，OK完成；
  双击▲先退出音量调整，再离开设置。
- 录音和播放中均能选声音；播放时换声音会用保留的录音重放。
  切换按住/自动模式会取消当前录音或播放，避免卡在持续工作的自动模式。
- 加强小声复读的持续音量归一化。录音去直流并在降采样前滤波，播放采用三次插值、
  分效果响度补偿及软限幅；机器人保留更多清晰人声，对讲机尾噪降低。
  主音量、持久化设置格式、分区及NABO素材均与preview.1一致。
- 音高分析拒绝含噪声时有歧义的子谐波候选；不承诺所有声学环境下的专业调音精度。

## 验证范围

```text
Build: PASS — 普通版和无线版ESP-IDF 5.5.3构建及归档校验
Host tests: PASS — 12种输入×12种变声、14种UI/音频状态、原型操作、
                   48种音高信号/1625帧；GitHub CI通过
Device tests: PASS — 发布的无线app已实刷并核对哈希；设置/纪录保留；
                     完成12种声音遍历；用户试听后接受当前结果并同意发布
Unverified: 整合镜像整文件安装；本版双机RF/距离回归；断电重启；更广泛的喇叭和听感条件
```

受控遍历中，20ms音频块的混音峰值3.245ms，音频读写错误为0。
这是混音耗时，不是全部任务延迟。复杂复读动画仍有慢帧，本次最高65ms。
8kHz ADPCM带宽及小喇叭仍有限制。合成小声音节提高约13.7dB，不能当作实际声学增益保证。

preview.1的双机结果仍属历史验证，本版没有重跑。新整合镜像的所有组件及空白区已离线校验；
保留设置升级只实际写入了app。见[脱敏验证记录](VALIDATION_0_2_0_PREVIEW_2.json)。

## 下载和使用

[Release附件](https://github.com/Liutupi/nabo-sound-lab/releases/tag/v0.2.0-preview.2)
包含完整ZIP、分立组件、整合镜像、清单和校验和。按[安装说明](FLASHING_0_2_0_PREVIEW_2.zh_CN.md)
操作，尤其注意兼容preview.1设备可只升级应用。

复读页按住OK说话、松开回放；▲换声音，▼切换按住/自动，OK停止播放，双击▲返回菜单。
无线对战仍是离线ESP-NOW三轮节奏游戏，两块工牌应使用同一版。
无需互联网、路由器或账号。

构建依赖和ESP-IDF 5.5.3环境见[BUILD](BUILD.zh_CN.md)，无线入口为
`firmware/tools/build-duel.ps1 -Action all`。本地重建需要单独验证，不能继承这些二进制哈希。
宿主音质检查见[测试说明](../tests/voice_host/README.zh_CN.md)。
